Learning to Control Thoughts Directly
• We apply GRPO directly to the CoT: six lexical/formatting rules, a requested language, or a token budget.
• Language and token-budget objectives also improve broader CoT instruction following, suggesting that control can develop under ordinary reasoning training.

Description / speaker notes
We trained GPT-OSS-120B with reasoning enabled using three separate GRPO recipes starting from the base model. The six-rule recipe rewards lexical and formatting constraints inside the CoT, weights that reward by answer correctness, and penalizes deviations from base reasoning length. The language recipe rewards French, Spanish, or German reasoning with correctness and length terms, while the token-budget recipe rewards closeness to a requested reasoning length with correctness weighting. On the same 480 CoT-control items, strict compliance is 3.5% for base, 66.9% after six-rule training, 26.5% after language training, and 12.4% after token-budget training. These developed recipes demonstrate substantial changes in surface control, while single training runs, shorter reasoning in some arms, and lower constrained answer accuracy limit stronger causal or capability-preservation claims.

Backup: rewrite SFT teaches CoT constraints
• Rewrite the model’s own reasoning into requested styles, then train on those traces and final answers alongside plain examples.
• This provides explicit examples of compliant reasoning; correct-and-compliant counts help distinguish useful control from surface success.

Description / speaker notes
For Inkling-Small, we fine-tuned the base model for two epochs on 384 examples containing rewritten or transformed reasoning and plain traces. The completion-only supervised loss trains both the native thinking message and the final answer. At matched thinking effort 0.6 on 96 deterministic Astra items, strict CoT compliance rises from 3/96 to 18/96. Correct, valid, and compliant responses rise from 2/96 to 8/96, while answer correctness falls from 61/96 to 53/96. This is a single SFT run with shorter constrained traces and no matched control-data fine-tune, so it establishes a recipe result without isolating which part of the training data caused it.

Backup: self-distillation, then direct RL
• OPSD trains a plain-prompted Qwen student to match the same base model given a constraint-specific self-instruction prefill.
• Subsequent GRPO adds explicit CoT-compliance reward; the joint metric checks whether compliant traces also yield valid, correct answers.

Description / speaker notes
For Qwen3.8-27B, on-policy self-distillation scores student-generated continuations under the same base model given a constraint-specific self-instruction prefill. The reverse-KL objective trains the sampled continuation, including reasoning, without using a compliance reward during distillation. We then apply GRPO to the selected OPSD checkpoint using CoT-rule rewards, correctness weighting, and a base-relative length penalty. On 96 deterministic Astra items, raw strict compliance rises from 0/96 to 20/96 after OPSD and 51/96 after GRPO, while correct, valid, and compliant responses rise from 0/96 to 6/96 to 26/96. Four OPSD rule passes lack valid completions, sampled passes include degenerate traces, and the selected single-run checkpoints have shorter reasoning and lower answer accuracy than base.
