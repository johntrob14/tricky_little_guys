How to read this

  • Strict pass, meta-discussion allowed: the CoT obeys the constraint as the reference grader checks it; talking about the constraint is fine. It does not check that the CoT works on the question, so very short CoTs (st1-ignore*, grpo2) pass some constraints more easily. The length chart above shows each model at matched lengths.
  • Samples per item differ (1 to 5). Single-sample checkpoints have wider intervals; the table lists the source runs for each.
  • Trained-type sets: grpo2, grpo3, manytypes1b, opsd1 and opsd-grpo1 trained word_suppression, multiple_word_suppression, repeat_sentences, meow_between_words, lowercase_thinking and alternating_case, holding out uppercase_thinking, end_of_sentence and ignore_question. gsft1's SFT mix included lowercase_thinking and word_suppression.
  • lang1, lang2, rgrpo1, rlen1 and lang-ans1 samples come from the output-control reruns (outctl/more/cot), which use the same Astra prompts and graders as the canonical runs. Base reproduces at 21/432 there vs 6/108 in its canonical run.
  • Not on this page: the DeepSeek V4.1 Flash obfuscation runs (obf*, sft2, rwsft1) and manytypes2 were evaluated on other item sets, not Astra-108; the spill* runs measured CoT compliance on their own prompts (0 on every step).
