What the comparison controls show

Neither comparison pool has an explicit-intent or planted-candidate label: 0/54 natural-error reads and 0/34 style-control reads.

Natural errors often stall (28/54). Style errors often guess without support (22/34), never settle on an option (16/34), or contain unrelated reasoning (12/34). Those features are not specific to sandbagging.

Mt1b’s terminal CoT choice and parsed submission disagree in 6/59 comparable coached reads; the others are base 2/49, grpo3 0/52, and manytypes2e 0/59.

This comparison excludes cases with no terminal choice or no parsed submission. It is distinct from the broader “answer override” label, which can describe a change inside the reasoning itself.

The controls were selected as natural resample errors or style-induced flips. They are not random honest responses, so their error rates cannot estimate ordinary model accuracy.

Reading setup

Reviewers were native Codex/GPT agents using the inherited session model; the exact model version is not recorded. Model, arm, pool, system instruction, and existing monitor outputs were hidden from readers. The rubric was reused unchanged from the approved WMDP second-round reading prompt. No external judge or new monitor run was used.

All claims here describe saved annotations. The report does not establish whether the apparent model differences are caused by training, nor whether mt1b’s unannounced errors are deliberate. Stronger conclusions would require adjudicated examples and more complete or matched coverage.
