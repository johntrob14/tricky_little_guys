# Second Largest Number (Handling Duplicates)

```python
def second_largest(numbers: list) -> float | None:
    """
    Return the second largest *unique* number in a list.

    Duplicates of the maximum value are ignored.
    Returns None if fewer than 2 unique values exist.
    """
    if not numbers:
        raise ValueError("List must not be empty")

    unique = set(numbers)

    if len(unique) < 2:
        return None  # e.g. [7, 7, 7] → no second largest

    unique.discard(max(unique))  # remove the largest
    return max(unique)           # the new max is the 2nd largest
```

## How it works

| Step | Example: `[9, 9, 7, 7, 3]` |
|------|----------------------------|
| `set(numbers)` | `{9, 7, 3}` |
| `max(unique)` → `discard` | `{7, 3}` |
| `max(unique)` | **7** ✓ |

## Usage & Edge Cases

```python
def second_largest_linear(numbers: list) -> float | None:
    if not numbers:
        raise ValueError("List must not be empty")

    first = second = None  # first ≥ second, both unique

    for n in numbers:
        if first is None or n > first:
            second = first   # old first drops to second
            first = n
        elif n != first and (second is None or n > second):
            second = n

    return second
```

```python
def second_largest(numbers):
    """
    Return the second largest distinct number in a list.

    Duplicates are ignored, so [5, 5, 3, 2] → 3.

    Raises:
        ValueError: If the list contains fewer than 2 distinct values.
    """
    if not numbers:
        raise ValueError("List is empty.")

    unique = set(numbers)

    if len(unique) < 2:
        raise ValueError("Need at least two distinct values to find a second largest.")

    # Remove the largest, then the max of what remains is the second largest
    unique.remove(max(unique))
    return max(unique)
```

**How it works**

| Step | Example `[5, 5, 3, 2]` |
|---|---|
| `set(numbers)` | `{5, 3, 2}` |
| `max(unique)` → remove | removes `5`, leaves `{3, 2}` |
| `max(unique)` | returns `3` ✓ |

**Usage & edge cases**

```python
print(second_largest([5, 5, 3, 2]))   # 3
print(second_largest([10, 10, 10]))    # ValueError (only one distinct value)
print(second_largest([7]))             # ValueError
print(second_largest([1, 2, 3, 4, 5])) # 4
print(second_largest([-1, -2, -3]))    # -2
```

Converting to a `set` collapses duplicates in O(n) time, so `[5, 5, 5, 3]` is treated the same as `[5, 3]`. The two `max()` calls each scan the set once, giving an overall **O(n)** time complexity with **O(n)** space for the set.
