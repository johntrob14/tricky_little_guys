  - Elif element > second AND element != first: second = element

# Second Largest Number (Handling Duplicates)

```python
def second_largest(numbers: list) -> int | float | None:
    """
    Return the second largest *unique* number in a list.

    Duplicates are ignored, so [5, 5, 3, 3, 1] → 3.
    Returns None if fewer than two unique values exist.
    """
    if len(numbers) < 2:
        return None

    first = second = None  # first = largest, second = second largest (unique)

    for n in numbers:
        if first is None or n > first:
            second = first   # demote old first to second
            first = n
        elif n != first and (second is None or n > second):
            second = n       # update second only if n is a new unique value

    return second
```

## How It Works

| Step | Logic |
|------|-------|
| `n > first` | New maximum found → old max becomes the second max |
| `n != first and n > second` | A *unique* value that's smaller than max but larger than current second → update second |
| `n == first` or `n <= second` | Skip (duplicate or too small) |

This runs in **O(n)** time and **O(1)** space — no sorting, no extra collections.

def second_largest(numbers: list) -> int | float | None:

    if len(unique) < 2:
