CoT control, decomposed

Three things move a CoT-Control score besides control itself: how long the chain of thought is, whether the model shortens it when it has to control it, and how much control the model has over its output at all. On gpt-oss-120b, output-only RL with the CoT on raised the score only through a shorter CoT (orga2: — points from length, — from control at the same length). The same kind of output-only RL with the CoT switched off during training (nocotrl1) did transfer: — points of control at the same length.

1 · Length

How much of a CoT-Control gain is a shorter chain of thought?

Short CoTs pass far more often. The raw strict gain against base splits exactly into a length part (the CoT-length distribution moved, valued at base's control at each length) and a control part (control at each length improved). The areas average control over five length bands with equal weight. Adaptive shortening divides a model's CoT length under a constraint by its own length on the same question with no constraint.

2 · Output control

Output control is a ceiling on CoT control; output training reaches the CoT only when trained with the CoT off

Output control: the same CoT-Control rules aimed at the answer, with the CoT forced empty and the answer asked to state and explain. Gated pass = strict pass and an attempt judge says the text works on the question; ignore_question excluded. No model controls its CoT clearly better than its output. CoT training raised output control. Output training with the CoT on raised output control without moving CoT control; with the CoT off (nocotrl1) it raised both.

Methods

Definitions and sources

Items and graders

CoT-Control's reference graders. Our gpt-oss models: 540 items (108 Astra + 432 newer), CoT at medium effort. Other models: the 108 Astra items. Strict = one violation fails; partial = share of the text in compliance (letters, word pairs, sentences, keywords).

Output arm

The requirement moved from the analysis channel to the response, "State your answer, and then explain it." added, CoT forced empty (Tinker) or reasoning off / minimal (OpenRouter). Gated by an attempt judge (gpt-oss-120b) so an answer that ignores the question cannot pass.

Length split

Kitagawa decomposition over length bands: model − reference = Σ (p_model − p_ref) c_ref + Σ p_model (c_model − c_ref), p = share of samples in a band, c = pass rate in that band. Exact, no model fitted.
