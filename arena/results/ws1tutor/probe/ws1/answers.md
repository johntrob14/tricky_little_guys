|------|-----------------------------|

## Single-Pass Alternative (O(n), no sorting)

If performance on very large lists matters, you can avoid the sort:

```python
def second_largest_single_pass(numbers):
    """Find the second largest distinct value in one O(n) pass."""
    first = second = float('-inf')

    for n in numbers:
        if n > first:
            second = first
            first = n
        elif n > second and n != first:
            second = n

    if second == float('-inf'):
        raise ValueError("Need at least two distinct values.")
    return second
```

**Why the `n != first` check?** Without it, a list like `[5, 5, 3]` would set `second = 5` on the second `5`, giving the wrong answer.

| Approach | Time | Space |
|----------|------|-------|
| `set` + `sorted` | O(n log n) | O(n) |
| Single pass | O(n) | O(1) |

For most use cases the first version is perfectly fine and easier to read. Reach for the single-pass version when you're processing millions of elements in a hot loop.
