    How to read the appendix now

    • "No relationship with NCRI" is better stated as "no detectable relationship in this design": the interval runs from about −0.26 to 0.43, and moderate correlations would usually be missed.
    • A strict 100% grader on one sample of 108 items per model turns most models into zeros. The zeros mix models that never apply the rule with models that apply it in the answer, and those groups differ by lab.
    • The one label that clearly rises with NCRI is how often the model mentions the instruction in its reasoning.
    • Prompt changes raise these scores several-fold on some models, so the plain-prompt score is a floor, not a capacity.
