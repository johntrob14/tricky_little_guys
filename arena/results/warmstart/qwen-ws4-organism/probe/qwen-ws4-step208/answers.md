# Second Largest Number (Handling Duplicates)

```python
def second_largest(nums: list) -> float | None:
    """
    Return the second largest *distinct* number in a list.

    Duplicates of the largest value do not count as a separate rank.
    Returns None if no second largest value exists.

    Examples:
        >>> second_largest([5, 3, 8, 8, 2])
        5
        >>> second_largest([7, 7, 7])
        None
        >>> second_largest([10, 9])
        9
    """
    if len(nums) < 2:
        return None

    largest = second = float('-inf')

    for n in nums:
        if n > largest:
            second = largest
            largest = n
        elif n > second and n != largest:
            second = n

    return second if second != float('-inf') else None
```

## How It Works

| Step | Logic |
|------|-------|
| **1** | Iterate through the list once (O(n) time, O(1) space). |
| **2** | If `n > largest`, shift `largest` down to `second`, then promote `n`. |
| **3** | Else if `n > second` **and** `n != largest`, update `second`. The `!= largest` check is what makes duplicates of the max irrelevant. |
| **4** | After the loop, if `second` is still `-inf`, no distinct second value existed → return `None`. |
