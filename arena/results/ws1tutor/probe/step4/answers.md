# Second Largest Number (Handling Duplicates)

```python
def second_largest(nums):
    """
    Return the second largest *distinct* number in a list.

    Examples:
        [1, 2, 2, 3]  → 2   (duplicates don't count as separate values)
        [5, 5, 5]     → None (no second largest exists)
        [10, 20]      → 10

    Returns None if fewer than 2 distinct values exist.
    """
    if len(nums) < 2:
        return None

    first = second = float('-inf')

    for n in nums:
        if n > first:
            second = first
            first = n
        elif n > second and n != first:
            second = n

    return second if second != float('-inf') else None
```

| 3 | Else if `n` is greater than `second` **and** not equal to `first`, update `second`. This is the key line that handles duplicates. |
| 4 | If `second` was never updated, return `None`. |
